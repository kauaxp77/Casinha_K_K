# Casinha K&K

Visualizador 3D do nosso apartamento (2 quartos + varanda), com medidas por cômodo, móveis e 3 opções de home office para o 2º quarto.

Abra o `index.html` no navegador ou acesse o deploy na Vercel.

**Como usar:** arraste para girar, use a rolagem (ou dois dedos) para zoom. Os botões no topo trocam entre 3D e planta, abaixam as paredes, ligam/desligam móveis e cotas, e o **Medir** mede a distância entre dois pontos do piso. Abaixo do modelo dá para trocar o layout do escritório (A, B, C).

> As medidas foram estimadas a partir da planta do folheto de vendas (margem de ±5 a 10 cm). Servem para planejar móveis, não para encomendar marcenaria sob medida.
